# 🏡 Airbnb Market Intelligence using Python

An end-to-end Exploratory Data Analysis (EDA) project built using Python to uncover insights from Airbnb listings across multiple countries. This project focuses on understanding pricing trends, customer engagement, property characteristics and amenities to derive meaningful business insights that can support data-driven decision-making.

---

## 📌 Project Overview

The objective of this project is to analyze Airbnb listing data and answer practical business questions through data cleaning, visualization and exploratory data analysis.

The project follows a structured analytics workflow:

- Data Cleaning & Preprocessing
- Feature Engineering
- Exploratory Data Analysis (EDA)
- Business Insights
- Actionable Recommendations

Rather than simply creating charts, each analysis is driven by a business question and concludes with observations and insights supported by the data.

## 📊 Business Questions Answered

This analysis explores several business-focused questions, including:

- How are Airbnb listings distributed across different price categories?
- Does a higher price lead to better customer ratings?
- How do property characteristics influence pricing?
- Which countries have the highest average listing prices?
- Which hosts manage the most listings?
- What are the most common amenities offered?
- How do popular amenities relate to listing prices?
- How does customer review activity vary across different rating groups?

---

## 🔍 Key Insights

Some of the major findings include:

- Budget listings make up the largest share of Airbnb properties.
- Larger properties generally command higher prices.
- Switzerland and the UAE have the highest average listing prices among countries with sufficient listings.
- WiFi, Kitchen and Free Parking on Premises are the most commonly offered amenities.
- Listings with higher ratings tend to receive more customer reviews.
- A small number of hosts manage a disproportionately large number of listings.
